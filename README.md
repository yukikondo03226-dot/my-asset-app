# マイ資産アプリ バックエンド＋画面 セットアップ手順

プログラミング不要で公開できるように、手順を1つずつ書いています。
上から順番に進めてください。

このフォルダには、データを取ってくるプログラム(`server.js`)と、
スマホで見る画面(`public/index.html`)の両方が入っています。

---

## ① このフォルダをGitHubにアップロードする

1. https://github.com/ にログインする
2. 右上の「+」→「New repository」をクリック
3. Repository name に `my-asset-app`(好きな名前でOK)と入力し、「Create repository」をクリック
4. 作成された画面の中にある「uploading an existing file」というリンク、または「Add file」→「Upload files」をクリック
5. このフォルダの中身をすべてアップロード
   - `server.js`
   - `package.json`
   - `.env.example`
   - `README.md`
   - **`public` フォルダごと**(この中に `index.html` が入っています)
   - `.env` という名前のファイルは絶対にアップロードしないでください
6. 一番下の「Commit changes」をクリック

**注意:`public`フォルダごとアップロードする方法**
GitHubのアップロード画面に、パソコンやスマホの「public」フォルダを丸ごとドラッグ&ドロップすれば、中の`index.html`も含めて自動でアップロードされます。フォルダごと選べない場合は、先に空の状態でCommitしてから、リポジトリ画面で「Add file」→「Create new file」を選び、ファイル名の欄に `public/index.html` と入力すると、自動でpublicフォルダが作られます。その中に`index.html`の中身を貼り付けてください。

---

## ② Renderで公開(デプロイ)する

1. https://render.com/ にアクセスし、「Get Started」→GitHubアカウントで登録
2. ダッシュボードで「New +」→「Web Service」を選択
3. さきほど作った `my-asset-app` リポジトリを選んで「Connect」
4. 設定画面で以下を入力
   - **Name**: 好きな名前(例: my-asset-app)
   - **Region**: Singapore(日本から一番近い)
   - **Build Command**: `npm install`
   - **Start Command**: `npm start`
   - **Instance Type**: Free
5. 画面を下にスクロールし、「Environment Variables」で以下の2つを追加
   - `JQUANTS_API_KEY` → J-Quantsで取得したAPIキーを貼り付け
   - `NEWSAPI_KEY` → NewsAPIで取得したAPIキーを貼り付け
6. 「Create Web Service」をクリック

数分待つと、画面上部に緑色で「Live」と表示されます。これで公開完了です。

---

## ③ 動作確認する

Renderの画面上部に表示されているURL(例: `https://my-asset-app-8b4e.onrender.com`)を、スマホやパソコンのブラウザで開いてください。

**画面(保有銘柄・オルカン・ニュース)がそのまま表示されれば成功です。**

うまく表示されない場合は、以下も確認してみてください。

- `https://(あなたのURL)/status` → 「マイ資産アプリ バックエンドAPI 稼働中です」と表示されればサーバー自体は動いています
- `https://(あなたのURL)/api/stocks` → 保有株の株価・PER/PBR
- `https://(あなたのURL)/api/orcan` → オルカンの基準価額
- `https://(あなたのURL)/api/news` → ニュース見出し一覧

エラーが出た場合は、そのエラーメッセージをそのまま教えてください。一緒に直しましょう。

---

## ④ スマホのホーム画面に追加する(アプリのように使う)

1. RenderのURLをスマホのブラウザ(Safari推奨)で開く
2. 共有ボタン(四角に上矢印のアイコン)をタップ
3. 「ホーム画面に追加」を選択

これで、ホーム画面のアイコンをタップするだけでアプリのように開けるようになります。

---

## ⑤ 注意点

- 保有銘柄・オルカンの保有状況は、**サーバー側のファイル(data/holdings.json)に保存**されるようになりました。Safariで開いても、ホーム画面のアイコンから開いても、同じ内容が表示されます。
- ただし、無料プランの特性上、**長期間(数週間など)アクセスがない場合や、Renderの基盤側のメンテナンスがあった場合に、保存内容がリセットされる可能性があります**。保有株数・取得単価などの大事な数字は、念のため他の場所にもメモしておくと安心です。
- 無料プランのため、しばらく(15分程度)アクセスがないとサーバーが自動で一時停止します。次にアクセスした時、起動までに30秒ほどかかることがあります(画面には読み込み中の表示が出ます)。
- 「今日に近い」株価・PER/PBRは松井証券の公開ページを直接読み取る**非公式な方法**で取得しています。
  - サイト側のページデザインが変わると、このプログラムが突然動かなくなることがあります
  - 動かなくなった場合は、`/api/stocks` にアクセスした時に返ってくるエラーメッセージ(`currentError`という項目)をそのまま教えてください。ページの中身を一緒に確認して直します
  - `longTermIndicator`(J-Quants由来のPER/PBR)は**約3ヶ月前時点のもの**です。「今日の値動き」ではなく「指標の推移を見る」参考値としてお使いください。
